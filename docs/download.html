开发状态:现在能用到什么程度

极早期开发阶段(alpha)。核心链路已经能跑通并且有自动化测试兜着,但界面与功能仍在快速变动, 不建议用在正式的生产服务器上;接口与数据格式也可能改,升级后偶尔需要重新登录一次。

✅ 已经能用

  • 账号注册 / 登录 / 退出,权限等级(Player / LAdmin / HAdmin / System)
  • 连接连官方服务端(默认)或自建子服务端(SAOS 模式)
  • 消息公告、定向推送、五种卡片(文本 / 更新 / 选择 / 填空 / 下拉),卡片按钮点了会回报服务端
  • 消息存档本地按来源分档保留、过期自动清理、可单条删除、重开后还在
  • 界面使用向导、设置页各分区、毛玻璃 / 半透明两档、左上角提示条
  • 社区功能经济、商店、蓝图画布、好友与组织等分区的基础版本
  • 子服务端自建 ZXMS:自动接入官方端、账号与封禁(账号 / IP / 机器码连坐)、公告与推送、控制台命令

⚠ 还不能用 / 正在做

  • 模组端 ZXMM协议还没定,尚未实现(打算做,不是砍掉)
  • 官方验证第二层已做到"验对端是不是官方";在线令牌与吊销还没做
  • 界面细节部分分区只有基础功能,排版与交互仍在调整
  • 平台目前只提供 64 位 Windows 客户端(单文件 AOT);没有移动端
  • 稳定性没有做长期运行压测;遇到问题请进群反馈(QQ 群 1129776132)

怎么用

  1. 解压到任意目录(别放需要管理员权限的地方)
  2. 改 config.ini:name 填服名,ozip/ozport 填官方服务端
  3. 双击运行,看到 账号认证通过 即成功
  4. 玩家用客户端以 SAOS 模式连你的 IP:czport

看完整部署教程

安装之后

1

启动向导

首次运行会走一遍使用向导:选连接方式 → 确认官方服务端地址 → 注册或登录账号。

2

官方服务端地址

默认就是 zxm.zincms.top:25000,不用手填。 想连别的服务端,要在设置里显式勾「自定义 IP:端口」并读完风险提示。

3

数据与更新

配置、消息与日志都在程序同目录;更新直接装新版本安装包即可,账号与本地消息不会丢。
