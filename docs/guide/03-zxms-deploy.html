六、子服务端 ZXMS:部署与使用

6.1 拿到程序

官网下载页 → 「子服务端 ZXMS」压缩包,解压到任意目录(别放需要管理员权限的目录,免得日志写不进去)。里面有:

ZincXManagerServer.exe     主程序(双击运行,带控制台)
config.ini                 配置(第一次运行会自动补全缺失项)
说明.txt                   同内容速查

运行后会生成:users.json(本服玩家账号)、bans.json(封禁)、messages.json(消息存档)、logs\(日志)。

6.2 配置 config.ini

键含义默认
name本服显示名(会下发给客户端,玩家看到的就是它)我的子服
czport玩家接入端口(防火墙要放行)21000
connectOS0 = 启动就连官方服务端;1 = 不连0
ozip官方服务端地址(可以写域名)127.0.0.1
ozport官方服务端端口25000
osuser你在官方端的账号名(第一次连上会自动注册)空
oshash密码密文(启动时问一次明文,只存密文)空
msgdays本服消息保留天数(下发给客户端)7
servercode本实例身份证(32 位十六进制,首次自动生成)自动
⚠️ servercode 和 oshash 千万别手改:
改显示名用控制台 name 新名字;改官方端账号/密码用 osuser 新账号 新密码(写成同名就只改密码)。
直接改 config 会被官方端判成"换了台实例",接入时报「身份不一致」。

6.3 第一次启动

  1. 双击 ZincXManagerServer.exe → 黑底控制台(管理入口就是这个控制台);
  2. 缺 osuser / oshash 时会问一次账号名与密码,问完写回 config(只存密文);
  3. 它会自动连官方服务端:账号不存在就自动注册;
  4. 看到这一行就成功了:
[ZXMOS] 账号认证通过:你的账号名|1|-

6.4 让玩家连上你的子服

玩家客户端:设置 → 模式与数据源 → 连接方式 SAOS → 数据源地址填 <你的域名或IP>:<czport> → 重连即可。

6.5 控制台命令(每条都有示例)

在子服那个黑窗口里直接敲、回车执行。示例里 > 后面是你要敲的,它下面的 输出: 是正常会看到的东西;
< > 是占位符,不要照抄尖括号。想先看全部命令:敲 help。

① 看状态

help —— 列出所有命令与用法

> help
输出:
  net  <子命令>:网络相关
    status        查看 ZXMOS 连接与客户端接入情况
    clients       查看连接登记表(身份 / 账号 / 等级 / 地址 / 在线 / 收包)
    reconnect     断开并重新连接官方服务端
  info            查看本端身份:名称 / 账号 / 服务端码 / 机器码 / 连接状态
  name <新名称>    改本端显示名(会下发给客户端)
  ...

net status —— 官方端连接 + 客户端接入情况

> net status
输出:
[消息] 官方服务端:zxm.zincms.top:25000(已认证)
[消息] 客户端接入:0.0.0.0:21000 · 当前在线 3

net clients —— 在线登记表(身份 / 账号 / 等级 / 地址 / 在线 / 收包)

> net clients
输出:
身份        账号        等级     地址                在线      收包
ZXMC        xiaoming    Player   192.168.1.30:51234  00:12:31  48
ZXMC        admin       HAdmin   192.168.1.31:51240  00:03:02  12

info —— 本端身份一览(排错第一步)

> info
输出:
名称        锌能源子服
账号        ZXMS-Test
服务端码     ba97eb4c40f6c868c8698cfbf91aa3aa
机器码       9b2b9f53c975b7e78d2a6ac22bd9f865cd4924b774778ffe329eaedcf1abc2f5

net reconnect —— 断开并重连官方端(改完网络/配置后用)

> net reconnect
输出:
[ZXMOS] 连接失败: ...(若真的连不上)
[ZXMOS] 握手成功: ZXMOS ok

srv show —— 看本端接入官方端用的账号名

> srv show
输出:
接入官方服务端的账号:ZXMS-Test

② 改配置(别手改 config.ini)

name <新名称> —— 改显示名(对新接入的客户端立刻生效)

> name 锌能源二服
输出:
[配置] 名称已改为 锌能源二服(新接入的客户端会看到新名字)

osuser <新账号> <新密码> —— 改本端在官方端的账号/密码(需已连上官方端)

> osuser ZXMS-Test 新密码123
输出:
[ZXMOS] 改名成功:ZXMS-Test → ZXMS-Test

# 只想改密码:名字写成一样的即可
> osuser ZXMS-Test 另一个新密码
输出:
[ZXMOS] 改名成功:ZXMS-Test → ZXMS-Test

msgdays <1-365> —— 本服消息保留天数(下发给客户端)

> msgdays 14
输出:
[消息] 本服消息保留天数已设为 14 天,已通知 3 个在线客户端

③ 发消息(公告 / 定向推送)

卡片种类:不写就是 text;update(一个链接按钮)、choice(两个按钮)、input(输入框+确认)、select(下拉框+确认)。

notice <标题>|<正文>[|种类|主动作|次动作|选项] —— 给本服所有客户端发公告

# 纯文本公告
> notice 维护公告|今晚 23:00 停机维护,预计 30 分钟
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 是否同意(两个按钮)
> notice 是否同意|新协议要点见附件|choice|是|否
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 带链接按钮的更新提示
> notice 更新提示|加入 XXX 功能,修复已知 BUG|update|立刻下载并更新
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 填空(玩家填完点确认,内容会回报给你)
> notice 你的省份|请填写你所在的省份|input|确认
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 下拉选择(选项用逗号分隔)
> notice 版本选择|请选择你游玩的版本|select|||1.21.1,1.21,1.20.6
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

玩家点了按钮之后,你这边会看到动作回执:

输出:
[消息] xiaoming 在卡片「是否同意」上点了「否」(本服卡片)

push <账号> <标题>|<正文>[...] —— 只发给某个玩家

> push xiaoming 版本选择|请选一个版本|select|||1.21.1,1.21
输出:
[消息] 定向推送已发给 xiaoming(1 张卡片)

> push xiaoming 私信|你申请的补偿已到账
输出:
[消息] 定向推送已发给 xiaoming(1 张卡片)

④ 账号管理

user list —— 列出本服账号

> user list
输出:
ID   名称        等级
1    xiaoming    Player
2    admin       HAdmin

user reg <名称> <密码> <等级> —— 新建账号(等级 = Player / LAdmin / HAdmin / System)

> user reg xiaoming 密码123 Player
输出:
[账号] 已创建 xiaoming(ID 1,等级 Player)

> user reg admin 管理员密码 LAdmin
输出:
[账号] 已创建 admin(ID 2,等级 LAdmin)

user rep <名称或ID> <新密码> —— 改密码(玩家忘记密码就用它)

> user rep xiaoming 新密码456
输出:
[账号] 已修改 xiaoming 的密码

user rel <名称或ID> <新等级> —— 改等级

> user rel xiaoming HAdmin
输出:
[账号] xiaoming 的等级已改为 HAdmin

user del <名称或ID> —— 删账号

> user del xiaoming
输出:
[账号] 已删除 xiaoming

⑤ 封禁

ban user <名称或ID> [时长] [原因] [--ip] [--machine] —— 封号(可连坐 IP / 机器码)

# 只封账号
> ban user xiaoming
输出:
[封禁] 已封禁账号 xiaoming(永久)

# 封 3 天,带原因
> ban user xiaoming 3d 刷物品
输出:
[封禁] 已封禁账号 xiaoming(3 天),原因:刷物品

# 连坐:账号 + IP + 机器码一起封
> ban user xiaoming 7d 小号刷屏 --ip --machine
输出:
[封禁] 已封禁账号 xiaoming(7 天),并连坐 IP 与机器码

ban add —— 手动加一条封禁(按 IP / 机器码 / 账号)

> ban add ip 192.168.1.30 3d 攻击服务器
输出:
[封禁] 已加入:IP 192.168.1.30(3 天)

ban list —— 查封禁表

> ban list
输出:
编号  类型    目标                到期        原因
1     账号    xiaoming            永久        刷物品
2     IP      192.168.1.30        2026-10-14  攻击服务器

ban del <编号> —— 解封

> ban del 1
输出:
[封禁] 已解封第 1 条(账号 xiaoming)

exit —— 退出程序(会断开与官方端的连接)

> exit
输出:
[命令] 收到退出命令,正在退出...

⑥ 示例:一条完整的运营流程

> name 锌能源二服                        # 先改个名字
> msgdays 14                            # 本服消息留 14 天
> user reg admin 管理员密码 LAdmin        # 建个低管
> notice 开服公告|今晚 20:00 正式开服|choice|收到|没空
> push admin 值班安排|今天你值班        # 单独通知
> ban user 破坏者 7d 恶意破坏 --ip --machine
> net clients                          # 看看谁在线
> info                                 # 核对本端身份

6.6 子服常见问题

现象原因与处理
接入报「身份不一致」官方端登记的 servercode 和你现在的不一样(通常是 config.ini 被整体覆盖、码丢了)。① 把 servercode 改回原来那个;② 让官方端清掉这个服务端账号,你重连时会自动重新注册
接入报「密码错误」控制台敲 osuser 同一个账号名 新密码(这是改子服账号密码的唯一正确方式)
玩家连不上你的子服检查 czport 有没有被占用、防火墙有没有放行、玩家填的是不是你的公网地址
提示「对端不是官方服务端」官方发行的 ZXMS 只连官方服务端;确实要连自建端,在 config.ini 写 officialcheck=0(会记警告)
想换显示名但不想被当成"新实例"别改 config,用 name 命令

6.7 数据与备份

  • 要备份的:config.ini(含 servercode / oshash)、users.json、bans.json、messages.json;
  • 日志在 logs\,排错时按时间找最新的那份;
  • 换机器时把整个目录拷走即可(注意 servercode 必须一起带走,否则要重新登记)。
