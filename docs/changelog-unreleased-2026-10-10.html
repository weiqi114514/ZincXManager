[未发布] - 2026-10-10

新增(续)

  • 缺口③修复:经 ZXMS 中转的玩家 / 管理账号登录
  • ZXMS 转发登录时也追加 |relay 标记(此前只有注册带);ZXMOS 认出标记后改查用户账号表,
  • 并且不再把 ZXMS 这条连接登记成玩家、也不把 ZXMS 的 IP 记到玩家头上(机器码照记,连坐可用)。
  • 测试③ 13/13:中转玩家注册 → 登录成功 → 机器码落表 → 走用户表,全部通过。
  • 弹窗形态落地(填空 / 选择 / 双按钮)
  • 设置 → 模式与数据源:「改数据源地址…」= 填空弹窗(预填当前地址,打开即全选;校验 IP:端口 且只能一个冒号);
  • 「切换连接方式…」= 选择弹窗(SAOS / OS / OOS,选完立即写 config.ini)。
  • 设置 → 账户与安全:「清除本地登录记录…」= 双按钮确认(清掉记住的密文与免登录设置,服务端账号不受影响)。
  • 弹窗按钮支持 回车 = 主按钮、Esc = 取消。
