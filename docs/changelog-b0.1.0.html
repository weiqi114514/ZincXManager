Changelog · b0.1.0

[b0.1.0] - 2026-10-25

本版本主题:自动更新 + 小功能组 + 账号绑定。客户端能自己检查并装新版本;玩家进服要账号主人确认;ZXMM 通道连不上会自己收手。

新增 · 客户端自动更新

  • 启动自动检查:读 GitHub Releases 最新版,有新版弹「更新提示」(当前版本 → 新版本 + 更新日志链接,按钮 取消 / 立刻更新)。连不上只弹一条 Toast,不挡启动;24 小时内用缓存,避免接口限流
  • 一键更新:点「立刻更新」自动下载并按安装形态安装 —— MSI 版走 msiexec /qb(关掉程序后自动继续);便携版解压后生成替换脚本(等进程退出、覆盖文件、按开关重新拉起)。两种都提示「关掉程序、重开后就是新版本」
  • 下载镜像:设置 → 高级 → 下载镜像,表格编辑(地址 / 名称 / 优先级 / 启用);支持多条按顺序尝试,全部失败自动退回官方源。默认 https://gh-proxy.com/,可改可关
  • 设置 → 下载页:显示当前版本 + 检查更新按钮(检查中提示、有更新弹窗、已最新 / 获取失败各有提示)

新增 · 其它

  • ZXMM 专用通道重连策略:5 秒一轮、最多 5 次,失败即停并报错;新增控制台命令 zxmm connect(手动重连) 与 zxmm status(看状态)
  • MSI 安装包支持选择安装目录,默认目录改成 D:\ZincXManager(安装界面里可以改)

修复

  • 设置里点「下载」页一片空白(切页时漏发属性变更通知)
  • 版本比较把 a0.5.1 误判成比 b0.1.0 新(改为先比字母前缀再比数字)
  • 便携版更新脚本用系统默认编码写,中文安装路径下会失效(改 UTF-8 + chcp 65001)
  • 镜像 / 更新提示窗口顶部那条 1px 白缝(窗口内容不再套一层不透明 Border)

服务端

  • 协议 620~630:登录请求、登录确认、结果回传、超时通知、绑定码、绑定、解绑、绑定查询
  • 绑定表 Data/BindUser.txt、持久登录表 PersistentLogin.txt、登录日志 loginlog.log
  • 登录请求的 IP 归属地由服务端查询后随包带给客户端(内网标「内网」,查失败标「未知」)
  • 解绑会清持久登录表并踢掉在线玩家,改绑会清旧玩家的免登录记录

说明

  • 更新包从 GitHub Releases 下载,国内建议保留默认镜像;镜像挂了会自动退回官方源
  • MSI 版更新时会提示「请关闭本程序」—— exe 运行时文件被锁,安装要等程序退出才能覆盖
  • ZXMM 模组这次也一起发了(ZXMM-b0.1.0.jar),只装在服务端,客户端不需要
