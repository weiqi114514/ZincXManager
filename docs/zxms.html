子服务端 ZXMS 部署教程

从拿到 ZXMS 到能连上客户端,一步步来。

你需要准备

  • 机器一台常开的 64 位 Windows,能访问外网
  • 端口一个给玩家接入的端口(默认 21000),记得在防火墙放行
  • 官方服务端zxm.zincms.top:25000(客户端与子服都连它)
  • 子服账号不用自己注册 —— 首次启动会自动在官方端注册,密码你自己定

三分钟上手

  1. 下载并解压 ZincXManagerServer(子服务端压缩包)
  2. 改 config.ini:name 填你的服名,ozip/ozport 填官方服务端地址
  3. 双击运行,看到 账号认证通过 就成功了
  4. 让玩家用客户端以 SAOS 模式连你的 IP:czport

在下载页取「子服务端 ZXMS」压缩包,解压到任意目录(别放需要管理员权限的目录,免得日志写不进去)。解压后只有两个必需文件:

ZincXManagerServer.exe     主程序(双击运行,自带控制台窗口)
config.ini                 配置(第一次运行会自动补全缺失项)

运行起来之后还会在同目录生成:users.json(本服玩家账号)、bans.json(封禁)、messages.json(消息存档)、logs\(日志)。

用记事本打开,最常见的就是这七行:

name=我的子服            ; 显示名:会下发给客户端,玩家看到的就是它
czport=21000            ; 玩家接入端口(防火墙要放行这个端口)
connectOS=0             ; 0 = 启动就连官方服务端(默认);1 = 不连
ozip=zxm.zincms.top     ; 官方服务端地址
ozport=25000            ; 官方服务端端口
osuser=我的子服账号      ; 你在官方端的账号名(首次连上会自动注册)
msgdays=7               ; 本服消息保留天数(下发给客户端,决定它们本地留多久)

启动时还会发生两件事

  • 问密码第一次连官方端会问一次你给 osuser 定的密码,只保存密文(oshash)
  • 生成服务端码自动写入 servercode(32 位十六进制)——这是本实例的身份证

⚠ 这两样千万别手改

servercode 和 oshash 不要在记事本里改:

  • 改显示名控制台敲 name 新名字
  • 改账号/密码控制台敲 osuser 新账号 新密码(名字写一样 = 只改密码)

直接改 config 会让官方端认为"这不是登记的那台实例",接入时报「身份不一致」。

  1. 双击 ZincXManagerServer.exe,出现黑底控制台窗口
  2. 它会自动连官方服务端;账号不存在就自动注册(密码用启动时问你的那个)
  3. 看到这一行就成功了:[ZXMOS] 账号认证通过:我的子服账号|1|-
  4. 敲 info 可以核对身份:名称 / 账号 / 服务端码 / 机器码 / 连接状态
PS> info
名称        我的子服
账号       我的子服账号
服务端码     8bd806ba…(32 位十六进制)
机器码       9b2b9f53…(设备)
连接状态     已连接 zxm.zincms.top:25000(已认证)

客户端设置

  1. 打开客户端 → 左侧「设置」→「模式与数据源」
  2. 连接方式选 SAOS(子服务端 + 官方服务端)
  3. 「数据源IP/域名」填你的 IP:czport(例如 192.168.1.10:21000)
  4. 回主界面重新连接;登录后玩家就会登记在你这个子服下

检查有没有连上

PS> net status
官方服务端   zxm.zincms.top:25000(已认证)
客户端接入   0.0.0.0:21000

PS> net clients
玩家账号     等级     地址            在线
小明        Player   1.2.3.4:51234   00:12:31

看状态

net status      官方连接 + 客户端接入情况
net clients     在线登记表(账号/等级/地址/在线时长)
net reconnect   断开并重连官方服务端
info            本端身份一览
srv show        接入官方端用的账号名

改配置

name 锌能源子服              改显示名(玩家立刻看到)
osuser 新账号 新密码         改官方端账号/密码
msgdays 14                 本服消息保留天数(下发给客户端)

发消息

notice 维护公告|今晚 23:00 停机
notice 是否同意|新协议要点|choice|是|否
push 小明 私信|只给他看
通知种类:text / update / choice / input / select

账号与封禁

user list                    列出账号
user reg 小明 密码 Player     新建账号
user rep 小明 新密码          改密码
ban user 小明                封号(连坐 IP/机器码)
ban list / ban del 编号       查看 / 解封

接入报「身份不一致」

官方端登记的服务端码和你现在的不一样,通常是 config.ini 被整体覆盖过、servercode 丢了。 两条路:① 把 servercode 改回当初那个;② 让官方端清掉这个服务端账号,你重连时会自动重新注册。

接入报「密码错误」

控制台敲 osuser 同一个账号名 新密码 —— 名字写成一样的就只改密码(这是改子服账号密码的唯一方式)。

玩家连不上

依次检查:czport 有没有被别的程序占用、防火墙有没有放行、玩家填的是不是你的公网 IP。

提示「对方不是官方服务端」

官方发行的 ZXMS 只承认官方服务端。如果你确实要连自建端,在 config.ini 写 officialcheck=0 放行(会记一条警告)。

⚠ 安全提示:子服控制台就是管理入口,别把带控制台权限的窗口分享给别人;定期备份 config.ini 与 users.json/bans.json。
