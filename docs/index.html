Vs. mods & plugins

和别的管理
模组 / 插件
不一样

同样是管服:别人是往 MC 服务端里塞插件,我们是一个独立的程序 + 客户端。

独立程序
不塞进服务端

插件要绑 MC 版本、跟着服务端重启;这是个单独的程序,升级互不影响。

不挑服务端版本

MC 端升级,管理端不用跟着重编译。

崩了不影响开服

管理端挂掉,游戏照常跑。

不用装一堆前置

没有前置插件、依赖库、权限框架。

服务端也能是原版

不需要为了装插件换核心。

一套顶
五六个插件

经济、商店、银行、社区、组织,不用各装一个再对接。

数据本来就通

商店扣的钱就是银行里的钱,不用装桥接插件。

一套账号体系

社区账号、游戏角色、权限等级是同一份。

一个界面管全部

不用在五六个插件的配置文件之间来回切。

升级一起升

不会出现插件 A 支持、插件 B 不支持。

玩家有客户端
不靠敲指令

插件时代玩家靠聊天框记指令;这里有界面、有按钮。

图形界面操作

开店、转账、加好友都是点,不是记命令。

消息能排版

公告支持 Markdown / HTML,不再是一行字。

消息不会刷屏丢失

离线消息由服务端保留,上线补齐。

不用装客户端 mod

独立客户端,不污染游戏本体。

没有安装向导、没有运行时、没有环境依赖。

FAQ

常见问题

更多在 文档与帮助。

我没有自己的服务器,能用吗?

能。连官方服务端就能用社区、广场、消息这些;商店与自建社区内容需要自己的子服务端。

要装数据库或 .NET 吗?

不用。客户端是单文件程序;子服务端也是解压即用,数据就是同目录下的文件。

玩家会不会很难上手?

玩家只需要一个客户端。登录后看到的就是左侧几个入口,不需要再学第二套系统。

换电脑或换服怎么办?

整个文件夹拷走即可;换服在连接窗口里改地址端口,不用重装。
