ZincXManager

内置功能

管理与社区功能开箱即用，后续版本持续扩充。

白名单管理

集中维护服务器白名单，配合玩家申请流程完成审核与放行。

账号绑定

社区账号与游戏角色绑定，作为权限、经济与数据归属的依据。

经济系统

社区通用货币，支撑商店买卖、奖励发放与玩家间流转。

商店

由子服务端负责的数据计算与交易逻辑，支持商品与库存运营。

蓝图库

建筑蓝图的上传、检索与分发，官方蓝图库由 ZXMOS 提供。

消息与申请

面向低权限管理场景：发布公告、处理玩家申请等日常事务。

游戏内交互

模组端与子服务端通信，执行寄予物品、查看背包等指令。

系统级操作

系统模式下可进行文件操作、重启软件、按报备启用远程桌面等。

分布式设计

官方服务端与子服务端各司其职，社区与本地数据互不耦合。

分布式架构

客户端、子服务端、官方服务端与模组端通过网络通信协同工作。

ZXMC

客户端

提供用户操作界面，以及与子服务端或官方服务端通信的媒介。桌面程序，通常运行在个人 PC 上。

ZXMS

子服务端

负责大部分数据操作与计算，如商店、蓝图库。通常与 MC 服务端处于同一网络或同一台服务器。

ZXMOS

官方服务端

提供官方社区、官方蓝图库等功能，仅由 ZXM 官方运行，部署在官方服务器上。

ZXMM

模组端

与子服务端通信，负责执行下发的指令，如寄予玩家物品、查看玩家背包等。运行在 MC 服务端上。

中转说明

当 ZXMC 处于 SAOS 模式并连接到 ZXMS 时，客户端将通过 ZXMS 中转与 ZXMOS 通信；否则直接与 ZXMOS 通信。

连接模式与权限模式

按使用场景组合连接方式与权限级别。

连接模式（3 种）

  • OS（OnlyServer）：仅连接子服务端
  • OOS（OnlyOServer）：仅连接官方服务端
  • SAOS（ServerAndOServer）：可同时连接子服务端与官方服务端

权限模式（4 种）

  • Player：玩家模式，使用社区经济等玩家功能
  • LAdmin：低管模式，消息发布、玩家申请处理等低权限功能
  • HAdmin：高管模式，可控制 MC 服务端等高权限功能，兼容低权限
  • System：系统模式，最高权限，文件操作、重启软件、远程桌面等，不兼容低/高权限功能

关于项目

ZincXManager（锌X管理面板）是一款面向 Minecraft / 社区管理员、服主与玩家的一体化、综合性管理面板， 主要使用 C# 开发，采用客户端、子服务端与官方服务端的分布式架构，目标是在同一套体系内同时覆盖 服务端管理与社区运营。
