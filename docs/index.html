FAQ

常见问题

更多内容在文档与帮助里。

客户端要装 .NET 吗?

不用。发布的是 NativeAOT 单文件,三个原生 dll 和 exe 放一起就能跑。

OS / OOS / SAOS 有什么区别?

OS 只连子服务端;OOS 直连官方服务端;SAOS 先连子服务端、再由它转发官方。

要自己开子服务端吗?

不强制。想有独立的广场、账号与数据就部署 ZXMS;只想用官方社区,选 OOS 直连即可。

数据存哪?

配置、消息与日志都生成在 exe 同目录;换机整体拷走即可。
