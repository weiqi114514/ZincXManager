Architecture

一客户端,两种数据源

客户端只连一个入口:官方服务端,或者你自己的子服务端。子服务端再向上接官方,形成「客户端 → 子服 → 官服」的链路。

01 / CLIENT

ZXMC

客户端 · 玩家与管理员的入口

双击即用的桌面客户端:登录、聊天、好友、经济、社区、组织、管理都在这里。

  • 单实例运行,重复连接有拦截
  • 三种连接模式:OS / OOS / SAOS
  • 会话全程加密
02 / SUB-SERVER

ZXMS

子服务端 · 你自己的服务器

服主部署在自己的机器上,管理本服玩家、消息、经济与权限;向上与官方服务端互通。

  • 命令行运维:config / user / log / file
  • 广场名称、消息保留天数可配
  • 替玩家向官方转发请求
03 / OFFICIAL

ZXMOS

官方服务端 · 官方节点

官方运行的节点,负责账号、许可、社区广场与跨服数据;客户端也能直连它使用官方社区。

  • 账号 / 许可 / 封禁
  • 官方广场(锌源广场)
  • 拒绝未加密的直连登录
Features

管理与社区,同一套界面

左侧导航分成经济 / 社区 / 组织 / 管理四组子功能,消息面板常驻右侧,Markdown 与 HTML 都能直接渲染。

管理

服主与管理员的日常操作,按子功能拆开,点进去只看到这一件事。

白名单管理

维护玩家白名单,配合服务器注册、账号绑定一起用。

账号绑定

社区账号与游戏角色绑定,作为权限、经济、封禁的依据。

版本管理

客户端与服务端版本核对、升级提示。

数据统计

玩家、经济与消息的指标汇总。

社区

服务器广场(子服社区)与锌源广场(官方社区)两个来源,按实际连接情况出现。

服务器广场

子服务端的社区内容,名字由 ZXMS 配置决定。

锌源广场

官方服务端的社区内容,直连官方或经子服中转才显示。

好友与私聊

独立好友条,双击开聊天窗口,消息走加密会话。

消息中心

系统 / 公告 / 私信分类,Markdown 与 HTML 直接渲染。

经济与组织

商店、银行,以及个人 / 团队 / 企业三级组织。

商店

与玩家或官方进行交易。

银行

存取款、转账与利息。

组织

个人组织、团队组织、企业组织三级结构。

权限模式

Player 与管理员分权,细到每个子功能。
