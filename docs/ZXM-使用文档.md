# ZincXManager 使用文档

> 适用版本:0.1.0(极早期开发阶段) · 官网 <http://zxm.zincms.top/> · 交流群 QQ `1129776132`
> 本文只讲**客户端(ZXMC)**与**子服务端(ZXMS)**。官方服务端由官方运行,你直接连就行,不需要自建。

---

## 一、这套东西是什么

ZincXManager(锌X管理面板,简称 ZXM)是给 Minecraft 服主、社区管理员和玩家用的一体化管理面板:既能管 MC 服务端,也能做社区运营(账号与权限、白名单、经济与商店、蓝图、公告与消息推送)。

**你只需要装两个东西里的一个或两个:**

| 端 | 谁装 | 干什么 |
| --- | --- | --- |
| 客户端 ZXMC | 每个玩家 / 管理员 | 你操作的面板(桌面程序,Windows) |
| 子服务端 ZXMS | 想自己开一台子服的服主 | 替你的玩家做中转,管本服账号、封禁、消息 |

**官方服务端**由官方运行,提供官方社区与官方蓝图库,并负责给子服和客户端登记身份 —— 它是"官方提供的一项服务",**不用你搭建**。

> ⚠️ 最容易搞混的一点:**官方服务端 ≠ 子服务端**。
> 官方服务端是官方那一台(所有人共用,默认地址 `zxm.zincms.top:25000`);子服务端是**你自己那台**(你自己部署,玩家连你的地址)。

## 二、安装客户端(ZXMC)

1. 打开官网**下载页** <http://zxm.zincms.top/download.html>,取其中一个:
   - **安装包(推荐)**:`ZincXManagerClient-0.1.0-x64.msi`,双击安装,自动建开始菜单与桌面快捷方式;卸载在「应用和功能」里;
   - **免安装压缩包**:解压到任意文件夹,双击 `ZincXManagerClient.exe` 即可。
2. 系统要求:64 位 Windows 10 / 11。单文件程序,**不需要装 .NET 运行时**;首次运行可能提示"未知发布者"(用的是开发签名证书),点「仍要运行」即可。
3. 首次启动会走一遍**使用向导**:
   - 选连接方式(见下一节,新手用默认即可)
   - 官方服务端地址**已经默认填好** `zxm.zincms.top:25000`,不用改
   - 注册或登录账号(等级默认 Player)
4. 登录成功后进入主界面。

## 三、连接方式与权限等级

### 3.1 三种连接方式(设置 → 模式与数据源)

| 方式 | 含义 | 什么时候用 |
| --- | --- | --- |
| **OOS** | 只连官方服务端 | 普通玩家:只上官方社区 |
| **OS** | 只连子服务端 | 你有自己的子服,只用子服的功能 |
| **SAOS** | 同时连子服务端与官方服务端 | 最常见的玩法:连自己子服,同时享受官方社区;此时客户端**经由子服中转**与官方端通信 |

> 只有在 SAOS 且已连上子服时,客户端才走中转;否则直连官方端。

### 3.2 四种权限等级

| 等级 | 说明 |
| --- | --- |
| **Player** | 玩家:社区、经济、商店等玩家功能 |
| **LAdmin** | 低管:发公告、处理玩家申请等低权限管理 |
| **HAdmin** | 高管:可管 MC 服务端等高权限操作 |
| **System** | 系统:最高权限(文件操作、重启软件等),不兼容低/高管功能 |

## 四、客户端界面

左侧竖排是**分区**:经济 / 社区 / 组织 / 好友 / 设置 / 管理 / 小功能组。

### 4.1 消息面板(右侧)

- **公告**:服务端下发的消息,可能带按钮(见下方"五种卡片");
- **定向推送**:只发给你的私信;
- **五种卡片形态**:
  | 卡片 | 长什么样 | 点了会怎样 |
  | --- | --- | --- |
  | text | 标题 + 正文 | 只能看 |
  | update | 底部一个链接按钮 | 点按钮会把"你点了它"回报给服务端 |
  | choice | 两个按钮(是 / 否) | 同上,回报你选了哪个 |
  | input | 一个输入框 + 确认 | 把你输入的内容一起回报 |
  | select | 下拉框 + 确认 | 回报你选的项 |
- 每张卡片右上角有**删除**(只删本地存档,不影响服务端);标题右侧是这条消息的**时间**;
- 卡片底部显示**来源**:`ZXMS-<子服名>`(子服下发的)、官方端下发的、或 `ZXMC`(你本地产生的)。

### 4.2 消息存档与保留规则

消息会存在本地,重开客户端还在。清理规则:

- 客户端本地产的消息:按**客户端**设置的天数保留(默认 60 天,设置 → 模式与数据源 里可改);
- 官方服务端下发的消息:固定最多 **20 天**;
- 子服务端下发的消息:按**子服务端自己**的设置保留(子服默认 7 天)。

过期消息在打开客户端时自动清理。

### 4.3 提示条(toast)

左上角滑出的小条(约 3.6 秒后滑回),用来告诉你:补发完成「已加载 N 条历史消息」、收到新消息、卡片动作回执(服务端的 ok / err 原话)、删除消息等。最多同时留 4 条,颜色代表口气:普通 / 成功 / 提醒 / 失败。

### 4.4 设置页各部分

| 分区 | 内容 |
| --- | --- |
| 个性化 | 壁纸、毛玻璃 / 半透明两档、透明度、头像 |
| 模式与数据源 | 连接方式(OS/OOS/SAOS)、数据源地址、客户端消息保留天数 |
| 账户与安全 | 改密码、删除本地头像缓存、登录记录(免登录) |
| 下载 / 高级 / 管理 / 小功能组 | 各功能入口(随版本补全) |
| QQ / ZXM 绑定、连接服务器配置 | 绑定与连接相关设置 |

## 五、连接设置(重点)

### 5.1 连官方服务端(默认)

不用填:客户端默认就是 `zxm.zincms.top:25000`。设置 → 模式与数据源 里能看到「官方服务端(默认)」被选中,后面括号里是「(官方默认)」。

### 5.2 连自己开的子服务端

1. 设置 → 模式与数据源 → 连接方式选 **SAOS**(或 OS);
2. 「数据源IP/域名」填你的子服地址:`<域名或IP>:<czport>`,例如 `mc.example.com:21000` 或 `192.168.1.10:21000`;
3. 回主界面重新连接;登录后玩家就会登记在你的子服下。

> 地址填**域名**也可以(客户端连的时候自己做 DNS 解析)。

### 5.3 自定义官方服务端地址(有风险,会拦你一下)

勾「自定义 IP/域名:端口」并读完风险说明(主按钮**读满 5 秒**才可点)后才能改。说明里写的就是实情:

- 第三方官方服务端可能**窃取你的个人信息**(如密码);
- 第三方服务端**可能被修改**,无法保证隐私安全;
- 可能**无法正常使用** ZXM 专有的跨子服务端功能和其他社区功能;
- **官方服务端和子服务端不是一个东西**,别弄混。

点「算了,保持官方」会自动回到官方默认地址。

## 六、子服务端 ZXMS:部署与使用

### 6.1 拿到程序

官网下载页 → 「子服务端 ZXMS」压缩包,解压到任意目录(别放需要管理员权限的目录,免得日志写不进去)。里面有:

```
ZincXManagerServer.exe     主程序(双击运行,带控制台)
config.ini                 配置(第一次运行会自动补全缺失项)
说明.txt                   同内容速查
```

运行后会生成:`users.json`(本服玩家账号)、`bans.json`(封禁)、`messages.json`(消息存档)、`logs\`(日志)。

### 6.2 配置 config.ini

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `name` | 本服显示名(会下发给客户端,玩家看到的就是它) | 我的子服 |
| `czport` | **玩家接入端口**(防火墙要放行) | 21000 |
| `connectOS` | 0 = 启动就连官方服务端;1 = 不连 | 0 |
| `ozip` | 官方服务端地址(**可以写域名**) | 127.0.0.1 |
| `ozport` | 官方服务端端口 | 25000 |
| `osuser` | 你在官方端的账号名(第一次连上会**自动注册**) | 空 |
| `oshash` | 密码密文(启动时问一次明文,只存密文) | 空 |
| `msgdays` | 本服消息保留天数(下发给客户端) | 7 |
| `servercode` | 本实例身份证(32 位十六进制,**首次自动生成**) | 自动 |

> ⚠️ **`servercode` 和 `oshash` 千万别手改**:
> 改显示名用控制台 `name 新名字`;改官方端账号/密码用 `osuser 新账号 新密码`(写成同名就只改密码)。
> 直接改 config 会被官方端判成"换了台实例",接入时报「身份不一致」。

### 6.3 第一次启动

1. 双击 `ZincXManagerServer.exe` → 黑底控制台(管理入口就是这个控制台);
2. 缺 `osuser` / `oshash` 时会**问一次账号名与密码**,问完写回 config(只存密文);
3. 它会自动连官方服务端:**账号不存在就自动注册**;
4. 看到这一行就成功了:

```
[ZXMOS] 账号认证通过:你的账号名|1|-
```

### 6.4 让玩家连上你的子服

玩家客户端:设置 → 模式与数据源 → 连接方式 **SAOS** → 数据源地址填 `<你的域名或IP>:<czport>` → 重连即可。

### 6.5 控制台命令(每条都有示例)

> 在子服那个黑窗口里直接敲、回车执行。示例里 `>` 后面是你要敲的,**它下面的 `输出:` 是正常会看到的东西**;
> `< >` 是占位符,不要照抄尖括号。想先看全部命令:敲 `help`。

```

#### ② 改配置(别手改 config.ini)

**`name <新名称>`** —— 改显示名(对新接入的客户端立刻生效)

```
> name 锌能源二服
输出:
[配置] 名称已改为 锌能源二服(新接入的客户端会看到新名字)
```

**`osuser <新账号> <新密码>`** —— 改本端在官方端的账号/密码(需已连上官方端)

```
> osuser ZXMS-Test 新密码123
输出:
[ZXMOS] 改名成功:ZXMS-Test → ZXMS-Test

# 只想改密码:名字写成一样的即可
> osuser ZXMS-Test 另一个新密码
输出:
[ZXMOS] 改名成功:ZXMS-Test → ZXMS-Test
```

**`msgdays <1-365>`** —— 本服消息保留天数(下发给客户端)

```
> msgdays 14
输出:
[消息] 本服消息保留天数已设为 14 天,已通知 3 个在线客户端
```

#### ③ 发消息(公告 / 定向推送)

卡片种类:不写就是 `text`;`update`(一个链接按钮)、`choice`(两个按钮)、`input`(输入框+确认)、`select`(下拉框+确认)。

**`notice <标题>|<正文>[|种类|主动作|次动作|选项]`** —— 给本服所有客户端发公告

```
# 纯文本公告
> notice 维护公告|今晚 23:00 停机维护,预计 30 分钟
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 是否同意(两个按钮)
> notice 是否同意|新协议要点见附件|choice|是|否
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 带链接按钮的更新提示
> notice 更新提示|加入 XXX 功能,修复已知 BUG|update|立刻下载并更新
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 填空(玩家填完点确认,内容会回报给你)
> notice 你的省份|请填写你所在的省份|input|确认
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)

# 下拉选择(选项用逗号分隔)
> notice 版本选择|请选择你游玩的版本|select|||1.21.1,1.21,1.20.6
输出:
[消息] 公告已下发(1 张卡片,覆盖 3 个在线客户端)
```

玩家点了按钮之后,你这边会看到**动作回执**:

```
输出:
[消息] xiaoming 在卡片「是否同意」上点了「否」(本服卡片)
```

**`push <账号> <标题>|<正文>[...]`** —— 只发给某个玩家

```
> push xiaoming 版本选择|请选一个版本|select|||1.21.1,1.21
输出:
[消息] 定向推送已发给 xiaoming(1 张卡片)

> push xiaoming 私信|你申请的补偿已到账
输出:
[消息] 定向推送已发给 xiaoming(1 张卡片)
```

```

```

```

**`user del <名称或ID>`** —— 删账号

```
> user del xiaoming

```

#### ⑤ 封禁

**`ban user <名称或ID> [时长] [原因] [--ip] [--machine]`** —— 封号(可连坐 IP / 机器码)

```
# 只封账号
> ban user xiaoming
输出:
[封禁] 已封禁账号 xiaoming(永久)

# 封 3 天,带原因
> ban user xiaoming 3d 刷物品
输出:
[封禁] 已封禁账号 xiaoming(3 天),原因:刷物品

# 连坐:账号 + IP + 机器码一起封
> ban user xiaoming 7d 小号刷屏 --ip --machine
输出:
[封禁] 已封禁账号 xiaoming(7 天),并连坐 IP 与机器码
```

**`ban add`** —— 手动加一条封禁(按 IP / 机器码 / 账号)

```
> ban add ip 192.168.1.30 3d 攻击服务器
输出:
[封禁] 已加入:IP 192.168.1.30(3 天)
```

**`ban list`** —— 查封禁表

```
> ban list
输出:
编号  类型    目标                到期        原因
1     账号    xiaoming            永久        刷物品
2     IP      192.168.1.30        2026-10-14  攻击服务器
```

**`ban del <编号>`** —— 解封

```
> ban del 1
输出:
[封禁] 已解封第 1 条(账号 xiaoming)
```

**`exit`** —— 退出程序(会断开与官方端的连接)

```
> exit
输出:
[命令] 收到退出命令,正在退出...
```

#### ⑥ 示例:一条完整的运营流程

```
> name 锌能源二服                        # 先改个名字
> msgdays 14                            # 本服消息留 14 天
> user reg admin 管理员密码 LAdmin        # 建个低管
> notice 开服公告|今晚 20:00 正式开服|choice|收到|没空
> push admin 值班安排|今天你值班        # 单独通知

> net clients                          # 看看谁在线
> info                                 # 核对本端身份
```


### 6.6 子服常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 接入报「身份不一致」 | 官方端登记的 `servercode` 和你现在的不一样(通常是 `config.ini` 被整体覆盖、码丢了)。① 把 `servercode` 改回原来那个;② 让官方端清掉这个服务端账号,你重连时会自动重新注册 |
| 接入报「密码错误」 | 控制台敲 `osuser 同一个账号名 新密码`(这是改子服账号密码的唯一正确方式) |
| 玩家连不上你的子服 | 检查 `czport` 有没有被占用、防火墙有没有放行、玩家填的是不是你的公网地址 |
| 提示「对端不是官方服务端」 | 官方发行的 ZXMS 只连官方服务端;确实要连自建端,在 `config.ini` 写 `officialcheck=0`(会记警告) |
| 想换显示名但不想被当成"新实例" | 别改 config,用 `name` 命令 |

### 6.7 数据与备份

## 七、客户端常见问题(FAQ)

**连不上/一直转圈?**
1. 地址端口对不对(官方端默认 `zxm.zincms.top:25000`,自建子服填 `你的地址:czport`);2. 服务端在不在线;3. 服务器防火墙/安全组有没有放行端口;4. 换网络试试(有些网络屏蔽非标准端口)。

**提示「对方不是官方服务端」?**
说明你连的这台不是官方端(自建服务端就会这样),客户端不会主动断开,但功能可能受限。确实要连自建端,在客户端 `config.ini` 写 `allowunverified=1`。

**消息过一阵不见了?**
过期自动清理,规则见 4.2。重要消息请自行留存。

**提示"未知发布者"/杀毒软件报毒?**
用的是开发签名证书,点「仍要运行」即可;文件都是从官网下载页拿的就不会有问题。

**毛玻璃不生效?**
需要 Windows 10/11 且系统设置里开启了"透明效果";也可以切成"半透明"档。

**忘记密码?**
子服:请管理员用 `user rep <名称> <新密码>` 重置。官方账号:在客户端登录页重新注册或联系官方。

**数据存在哪?**
都在客户端 exe 同目录:`config.ini`(配置)、`messages.json`(消息存档)、`logs\`(日志)。换机器把整个目录拷走即可。
