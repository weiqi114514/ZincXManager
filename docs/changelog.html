[a0.4.0] - 2026-10-18

子功能页 + 消息渲染 + 广场:经济/社区/组织/管理四页都改成子功能卡片;消息面板支持 Markdown 与 HTML;服务器广场与锌源广场按实际连接区分数据来源;ZXMOS 补上加密协商。

新增

  • 子功能页:经济(商店/银行)、社区(服务器广场/锌源广场)、组织(个人/团队/企业组织)、管理(版本/数据源/服务器/数据统计),统一卡片模板 + 设计稿描边图标
  • 好友独立窗体:点「好友」打开条状好友条,双击好友再开聊天窗体
  • 消息面板支持 Markdown / HTML:消息卡片、日志、更新日志、自定义网页都按格式渲染,自动识别
  • 消息面板全屏按钮:左下角,在工作区内 500ms 滑动展开(四周留 10px),图标随状态切换
  • 服务器广场名称可自定义:ZXMS 的 config 新增 squarename,下发给客户端当标题
  • 锌源广场按实际连接显示:直连 ZXMOS 或经子服连官方才显示
  • 「在浏览器打开」可选浏览器:Edge / Chrome / Firefox(火狐) / 360
  • ZXMOS 加密协商:补 380/381 会话握手,并拒绝未加密的直连登录
  • ZXMS 连 ZXMOS 先握手:先协商密钥再上线登录
  • 主界面默认页;点左上 Logo 回默认页;启动连接流程时关闭主界面

修复

  • Toast 长文本显示不全:改成图标/文字两列,文字按剩余宽度换行
  • OOS 官方服务端地址:从设置页搬到连接流程窗口(5 秒风险说明 + 填 IP:端口)
  • 设置页不再能改模式和 IP:只显示当前值
  • 消息窗口收起规则:只有默认页显示消息面板
  • 子功能卡片高度 140 → 126

[a0.3.2] - 2026-10-17

启动流程与外观修复:打开客户端先测数据源,连不上直接弹窗并停在连接界面;同时修掉「配色永远默认蓝」「亚克力透明度调不动」「半透明档还是亚克力」。含 a0.3.1 的加密会话与登录挑战-响应。

安全

  • 会话加密:握手 380 / 381 交换 ECDH(P-256)公钥,HKDF-SHA256 派生两把 AES-256-GCM 密钥,之后所有报文加密(包头 Flags 0x0001)
  • 登录挑战-响应:nonce(秒 + 32 位随机)每次不同,proof = SHA256(密码密文 : nonce);服务端按存的密文重算,nonce 一次性 + 5 分钟窗口
  • 服务端拒绝未加密的明文登录(返回 err|客户端版本过旧)

新增

  • 启动数据源自检:等待窗 → 连上才进登录(或免登录主界面);连不上弹「连接 ZXMS 失败 / 连接 ZXMOS 失败」并停在连接窗口
  • 连接窗口「去登录」:连接成功后进登录界面,不再直进主界面
  • OOBE 第 5 步连接失败会弹窗
  • ZXMOS 新增 config 配置模式(name / port / msgdays);ZXMS 配置表补齐 oshash / configver
  • 配置模式拒绝其它命令(提示先 exitc);启动横幅带版本号 -a0.3.2

修复

  • 配色从未应用:ThemeManager.ApplySaved() 无人调用,永远默认蓝;现在启动即按 config.ini 的 theme / glass / alpha 生效
  • OOBE 模式选择高亮写死:改用 ThemeLight / ThemeMuted / ThemeSecondary / ThemePrimaryDark
  • 亚克力档透明度固定:所有表面按「设计基准 × 滑杆比例」整体缩放(80/90/36/36/40/60%)
  • 半透明档仍是亚克力:切档时重新套窗口材质(半透明 → Transparent)

[未发布] - 2026-10-07

新增

  • ZXMOS · 黑名单(srv ban)与账号归档
  • 新文件 ZincXManagerOServer/Blacklist.cs:归档实现,把被拉黑 ZXMS 名下的玩家账号连同拉黑信息一起挪到
  • blacklist/zxms/<名称>/:
  • accounts.json:名下账号(字段与账号表一致,解封时能原样读回)
  • info.json:拉黑时间 / 到期时间 / 原因 / 来源 IP / 账号数
  • ZXMOS 新增命令:
  • srv ban <名称或ID> [perm|30d|12h] [原因] —— ① 归档该 ZXMS 名下账号 → ② 按「账号名 + 它的 IP」封禁 → ③ 断开它已连上的连接
  • srv unban <名称或ID> —— 解封,并从 blacklist/zxms/<名称>/accounts.json 把账号读回账号表(保留 owner / 最后登录 IP / 机器码)
  • srv blacklist —— 列出已归档的 ZXMS 与拉黑信息
  • ban user <名称或ID> [时长] [原因] [--ip] [--machine] —— 与 ZXMS 侧对齐,支持连坐最后登录 IP / 机器码
  • 协议
  • Protocol.ServerName = 201:服务端 → 对方,负载为服务端显示名。
  • 客户端 · 个性化
  • 新增配色 巨硬蓝(微软 Fluent 蓝):#0078D4 / #005A9E / #2899F5 / #A9D3F2 / #DEECF9 / #7FA8C9。
  • 新增 毛玻璃(亚克力) 开关(设置 → 个性化,以及 OOBE 第 2 步「个性化」):
  • 开 = 亚克力:背景按 Fluent 亚克力模糊(半径 30)、表面着色 80%
  • 关 = 半透明:背景不模糊、表面着色 60%
  • 默认开,记在 config.ini 的 glass=1/0
