Changelog · a0.5.0

[a0.5.0] - 2026-10-18

本版本主题:断线可感知 + 窗口可用 + 测试可回归。客户端不再"假在线",窗口在小屏上不再跑到屏幕外,全量测试换成 C# 程序。

新增

  • 断线心跳与自动重连:客户端每 5 秒检查一次连接。断了立刻在左上角弹红色提示条「与服务端的连接已断开,尝试重连」,之后每 5 秒自动重连一次,提示「正在重连 N/5」
  • 重连彻底失败切回连接流程:连续 5 次没连上,关闭主界面、切回连接窗体,并弹窗给出失败原因(含最近一次错误),而不是让用户对着"假在线"的界面发呆
  • 窗口尺寸自适应:启动时按屏幕工作区自动缩放(留 40px 边距),1366×768@125% 这类小屏上右侧消息面板不会再跑到屏幕外
  • 窗口可自由拉伸:最小尺寸从 960×620 降到 720×480,并在右下角加了一个拖拽手柄(两条斜纹),拖动即可改窗口大小

改进

  • 登录按钮支持回车:登录按钮设为默认键,输完密码直接按回车即可登录,不再必须去点按钮
  • 弹窗 Esc = 取消:Esc 关掉弹窗与点右上角关闭同义,一律按"取消"处理(风险说明这类守门弹窗也能随手关掉)
  • 弹窗居中于宿主:按宿主窗口的屏幕位置显式计算,不再依赖系统 CenterOwner(那个在某些环境下会退化成屏幕居中)
  • 全量测试改成 C# 程序(ZincXManagerTests,12 个套件 91 项断言):起真实进程、走真实协议、十几秒跑完;打包脚本会在出 MSI 前先跑一遍,不绿就不许打包

修复

  • 小屏下窗口超出屏幕、右侧面板看不见
  • 断线后客户端毫无提示、仍显示已登录

说明

  • 本次重新生成了官方许可证钥匙对(OfficialKey.cs 两份已同步)。旧钥匙签的证需要重新签发才能被新构建认可
  • 全量测试程序随安装包一起分发(ZincXManagerTests-<版本>-win-x64.zip),可直接双击运行做自检

[a0.5.0] - 2026-10-18

连接可靠性:修掉「重复连接 / 连错目标」这一组问题,避免服务端挂一堆僵尸连接。

修复

  • 重复点「连接」不再叠加连接:同一目标已经连着时改为弹窗提示「已经连接」;换了地址/端口/模式才先断开再连新目标
  • 连接前先关旧连接:开始新连接前会关闭上一条,不再在服务端留下僵尸连接
  • 客户端单实例:同时只能开一个客户端,开第二个会自动退出
  • OOBE 连接按钮没按模式选目标:选 OOS 却用子服务端地址(czip)去连;现在连接窗口与 OOBE 都先按模式设目标(OOS → ozip/ozport)
  • OOBE 数据源页按模式显示地址:OS/SAOS 填子服务端,OOS 填官方服务端
  • OOBE 换目标会重连:先连 ZXMS 再改选 OOS 时,先断开再连官方端
  • 连接流程窗口不再重复弹出:已打开就置顶,不再新建

打包

  • 安装包 / 便携 ZIP 现在都带 UpdateLog.MD,客户端的更新日志页签不再空白
