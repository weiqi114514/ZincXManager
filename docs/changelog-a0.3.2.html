[a0.3.2] - 2026-10-17

启动流程与外观修复:打开客户端先测数据源,连不上直接弹窗并停在连接界面;同时修掉「配色永远默认蓝」「亚克力透明度调不动」「半透明档还是亚克力」。含 a0.3.1 的加密会话与登录挑战-响应。

安全

  • 会话加密:握手 380 / 381 交换 ECDH(P-256)公钥,HKDF-SHA256 派生两把 AES-256-GCM 密钥,之后所有报文加密(包头 Flags 0x0001)
  • 登录挑战-响应:nonce(秒 + 32 位随机)每次不同,proof = SHA256(密码密文 : nonce);服务端按存的密文重算,nonce 一次性 + 5 分钟窗口
  • 服务端拒绝未加密的明文登录(返回 err|客户端版本过旧)

新增

  • 启动数据源自检:等待窗 → 连上才进登录(或免登录主界面);连不上弹「连接 ZXMS 失败 / 连接 ZXMOS 失败」并停在连接窗口
  • 连接窗口「去登录」:连接成功后进登录界面,不再直进主界面
  • OOBE 第 5 步连接失败会弹窗
  • ZXMOS 新增 config 配置模式(name / port / msgdays);ZXMS 配置表补齐 oshash / configver
  • 配置模式拒绝其它命令(提示先 exitc);启动横幅带版本号 -a0.3.2

修复

  • 配色从未应用:ThemeManager.ApplySaved() 无人调用,永远默认蓝;现在启动即按 config.ini 的 theme / glass / alpha 生效
  • OOBE 模式选择高亮写死:改用 ThemeLight / ThemeMuted / ThemeSecondary / ThemePrimaryDark
  • 亚克力档透明度固定:所有表面按「设计基准 × 滑杆比例」整体缩放(80/90/36/36/40/60%)
  • 半透明档仍是亚克力:切档时重新套窗口材质(半透明 → Transparent)
