[a0.4.0] - 2026-10-18

子功能页 + 消息渲染 + 广场:经济/社区/组织/管理四页都改成子功能卡片;消息面板支持 Markdown 与 HTML;服务器广场与锌源广场按实际连接区分数据来源;ZXMOS 补上加密协商。

新增

  • 子功能页:经济(商店/银行)、社区(服务器广场/锌源广场)、组织(个人/团队/企业组织)、管理(版本/数据源/服务器/数据统计),统一卡片模板 + 设计稿描边图标
  • 好友独立窗体:点「好友」打开条状好友条,双击好友再开聊天窗体
  • 消息面板支持 Markdown / HTML:消息卡片、日志、更新日志、自定义网页都按格式渲染,自动识别
  • 消息面板全屏按钮:左下角,在工作区内 500ms 滑动展开(四周留 10px),图标随状态切换
  • 服务器广场名称可自定义:ZXMS 的 config 新增 squarename,下发给客户端当标题
  • 锌源广场按实际连接显示:直连 ZXMOS 或经子服连官方才显示
  • 「在浏览器打开」可选浏览器:Edge / Chrome / Firefox(火狐) / 360
  • ZXMOS 加密协商:补 380/381 会话握手,并拒绝未加密的直连登录
  • ZXMS 连 ZXMOS 先握手:先协商密钥再上线登录
  • 主界面默认页;点左上 Logo 回默认页;启动连接流程时关闭主界面

修复

  • Toast 长文本显示不全:改成图标/文字两列,文字按剩余宽度换行
  • OOS 官方服务端地址:从设置页搬到连接流程窗口(5 秒风险说明 + 填 IP:端口)
  • 设置页不再能改模式和 IP:只显示当前值
  • 消息窗口收起规则:只有默认页显示消息面板
  • 子功能卡片高度 140 → 126
