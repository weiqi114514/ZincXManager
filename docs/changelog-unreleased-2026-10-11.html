[未发布] - 2026-10-11

新增(续 8)

  • 全量测试合并成一个入口 _run-all.ps1:一条命令跑完 21 个套件(单元 + 场景 ①~⑫ + 身份码 + 官方验证 + GUI 类),
  • 自带端口预检、每个套件明细落盘(_回归明细\*.txt)、末尾总表,退出码 = 失败套件数;
  • 另带 -Only / -Skip / -List。旧的 _run-full.ps1 / _run-core.ps1 / _run-all-tests.ps1 退役。
  • 官网重写(zxm-website\):去掉源码构建步骤与源码仓库/开源协议链接;新增
  • 下载页(download.html,由打包产物自动生成版本/大小/SHA256)、子服务端 ZXMS 部署教程页(zxms.html)、
  • 更新日志页(changelog.html,由本文件自动生成)、sitemap 更新。
  • 客户端安装包:ZincXManagerClient-<版本>-x64.msi(全机器安装,自动建开始菜单 + 桌面快捷方式,可在「应用和功能」卸载)
  • + ZincXManagerClient-<版本>-win-x64-portable.zip(免安装);
  • 子服务端:ZincXManagerServer-<版本>-win-x64.zip(含 config.ini 模板)。
  • 一键出包脚本 _build-installer.ps1,产物与 SHA256 落到桌面测试包。
  • 安装图标 zxm.ico:6 个尺寸(16~256),按官网配色(深蓝底 + 绿色描边 + 绿 Z)现画现生成(_make-icon.ps1)。
