⑥ 关键链路

链路顺序用到的协议码要点
启动读 config.ini → 补默认值 → 起监听 → (子服)连官方端—缺配置项自动写回默认;端口被占用会直接报“监听失败”
客户端上线ZXMC → ZXMS:300 上线(负载 ZXMC:模式) → ZXMS 回 301300 / 301握手完成才算“在线”,连接表里能看到
子服上线ZXMS → ZXMOS:100 上线 → ZXMOS 回 101100 / 101之后 ZXMOS 才能给这个子服转发消息
身份下发服务端 → 对方:200 我是谁(ZXMS/ZXMOS) → 201 服务端名称200 / 201 / 202客户端标题栏显示的名字就来自这里
消息广播ZXMOS：500 公告 → ZXMS 原样转给自己名下所有 ZXMC500负载是消息卡片;子服只转发不解析正文
定向推送ZXMOS：501 目标账号|卡片 → 每跳按账号过滤,命中才投501不命中静默丢弃
卡片按钮ZXMC：502 动作|输入|原卡片 → 服务端回 503502 / 503服务端据此知道是哪张卡片、谁点的
历史补发ZXMC：505 要历史 → 服务端 504 逐条发 → 506 收尾504 / 505 / 506按“来源+消息号”去重;子服 504/505 两路合并
官方验证验证方：520 挑战(nonce) → 服务端：521 Base64(lic)|nonce|HMAC520 / 521只有登录过的连接才应答;校验机器码绑定
账号改名ZXMS → ZXMOS：611 改名 → 612 回执(ok|新名 或 err|原因)611 / 612控制台 osuser 命令触发
